# Excel工具集

一个功能强大的Excel处理工具，支持表头映射、数据合并和批量处理等功能。

## 主要功能

### 1. Excel处理器
- 支持源数据文件和模板文件的表头映射
- 支持多个源表头映射到同一个模板表头
- 自动处理数据合并，并在合并时保留源表头信息
- 支持大文件处理，采用流式处理方式（SXSSF）
- 实时显示处理进度
- 支持批量数据处理

### 2. 表头映射工具
- 可视化表头映射关系配置
- 支持多对一映射关系
- 支持映射关系的保存和加载
- 直观的拖拽式操作界面

### 3. 应用映射功能
- 支持将已配置的映射关系应用到新的Excel文件
- 支持批量处理大量数据
- 实时显示处理进度
- 自动处理数据格式转换

### 4. 跨表主键填充工具
- 支持A表与B表按主键逐行匹配
- 将源表数据列的值填充到目标表对应的列
- 支持大小写无关、自动去空格的模糊匹配
- 实时显示处理进度

### 5. 重复列合并工具
- 按指定列（如CustomerId）识别重复行
- 重复行的其他列自动用 `|` 拼接去重
- 支持自定义选择需要合并的列
- 适合批量去重、合并等场景

## 技术特点

- 使用Java Swing构建GUI界面
- 采用Apache POI 5.2.3处理Excel文件
- 支持大文件处理（使用SXSSF流式模式，100行内存窗口）
- 内存优化设计，支持处理百万级数据
- 所有耗时操作使用SwingWorker异步执行，不阻塞UI
- 详细的日志记录（Log4j2）

## 系统要求

- Java 8或更高版本
- 操作系统：Windows/Linux/MacOS
- 内存：建议4GB以上
- 磁盘空间：根据处理文件大小而定

## 项目结构

```
src/
├── main/
│   ├── java/com/xzy/
│   │   ├── ExcelTools.java               ← 主程序（5 Tab GUI）
│   │   ├── CrossSheetFiller.java         ← 跨表填充（@Deprecated，被Tab调用）
│   │   └── DuplicateColumnMerger.java    ← 重复列合并（@Deprecated，被Tab调用）
│   └── resources/
│       ├── log4j2.xml                    ← 日志配置
│       └── META-INF/MANIFEST.MF
├── legacy/                               ← 旧版代码归档（不参与编译）
docs/                                     ← 项目文档
test-data/                                ← 测试数据
launch4j-config.xml                       ← Windows EXE打包配置
pom.xml                                   ← Maven构建配置
```

## 构建与运行

```bash
mvn clean compile          # 编译
mvn package                # 打包（生成 target/excel-processor-1.0-SNAPSHOT.jar）
java -jar target/excel-processor-1.0-SNAPSHOT.jar   # 运行
```

Launch4j可通过`launch4j-config.xml`将JAR打包为`ExcelProcessor.exe`。

## 使用说明

### Excel处理器

1. 选择文件
   - 点击"选择文件"按钮
   - 选择源数据文件（包含原始数据的Excel文件）
   - 选择模板文件（目标格式的Excel文件）

2. 配置映射关系
   - 在左侧列表中选择源表头
   - 在右侧列表中选择目标表头
   - 点击"添加映射"按钮建立映射关系
   - 可以建立多个映射关系

3. 保存文件
   - 点击"保存文件"按钮
   - 选择保存位置
   - 等待处理完成

### 表头映射工具

1. 上传关系表
   - 点击"上传关系表"按钮
   - 选择包含映射关系的Excel文件

2. 建立映射关系
   - 在左侧选择源字段
   - 在右侧选择目标字段
   - 点击"保存映射关系"按钮

3. 查看映射关系
   - 在下方列表中查看已保存的映射关系

### 应用映射

1. 上传目标表
   - 点击"上传目标表"按钮
   - 选择需要应用映射的Excel文件

2. 选择字段
   - 选择查找字段（用于查找映射关系的字段）
   - 选择填充字段（用于填充映射值的字段）

3. 应用映射
   - 点击"应用映射"按钮
   - 选择保存位置
   - 等待处理完成

### 跨表主键填充

1. 选择源表和目标表
2. 配置匹配表头（源表和目标表的主键列）
3. 配置数据表头（源表数据列和目标表填充列）
4. 点击"开始填充"，选择输出路径

### 重复列合并

1. 选择输入文件
2. 选择重复列（用于判断重复的列）
3. 勾选要合并的列
4. 点击"开始合并"，选择输出路径

## 注意事项

1. 文件大小限制
   - 单个文件最大支持1000MB
   - 建议分批处理超大文件

2. 数据格式
   - 支持.xlsx和.xls格式
   - 建议使用.xlsx格式以获得更好的性能

3. 内存使用
   - 程序会自动优化内存使用
   - 处理大文件时建议关闭其他内存占用大的程序

4. 错误处理
   - 程序会自动记录错误日志
   - 遇到错误时会显示详细的错误信息

## 常见问题

1. 如何处理大文件？
   - 程序采用流式处理方式，支持处理大文件
   - 建议分批处理，每批不超过1000MB

2. 如何处理多个表头映射到同一个目标表头？
   - 程序会自动合并数据
   - 合并时会保留源表头信息，格式为：源表头：数据 | 源表头：数据

3. 如何处理公式？
   - 程序会自动计算公式结果
   - 输出文件中只保存计算结果，不保存公式
